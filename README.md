# Web personal (HTML y CSS)

Página de perfil personal creada como ejercicio del ciclo de Desarrollo de Aplicaciones Web.

**Ver la web:** https://mariamendeznavas.github.io/perfil-html-css/

## Qué incluye
**HTML**
- Estructura con etiquetas semánticas de HTML5: `header`, `nav`, `main`, `section`, `article` y `footer`.
- Menú de navegación con enlaces internos (anclas) a cada sección.
- Tabla de proyectos con `thead` y `tbody`.
- Enlace externo con `target="_blank"`.

**CSS**
- Contenedor centrado con ancho máximo y sombra.
- Menú con efecto `hover` y transición suave.
- Fotografía circular con `float`, `object-fit` y `clearfix`.
- Estilos para títulos, secciones, tabla y pie de página.

## Tecnologías
HTML5 · CSS3 · GitHub Pages
